## 소개
이 프로젝트는 기존에 포인핸드 웹사이트에서 동물검색 기능을 추가하고 로그인탭 기능을 추가하고 공공API를 이용해서
데이터를 받아오는 포트폴리오 프로젝트 입니다.

## 주요 기능
- **공공 API 연동 및 데이터 실시간 조회**: 유기동물 보호 공공 데이터를 활용해 실시간으로 동물 정보 목록 조회 및 상세 정보 확인 가능
- **로그인 상태 관리(데모)**: 폼 유효성 검사 후 localStorage에 사용자 ID를 저장하여 페이지 간 로그인 상태 유지
- **동물 맞춤 검색 및 필터링**: 지역, 축종, 품종, 상태 등 다양한 조건으로 필요한 동물 정보를 빠르게 탐색
- **상세 정보 및 반응형 UI**: 동물의 상세한 특징과 보호소 정보를 직관적으로 확인할 수 있는 상세 페이지 제공

## 📁디렉토리 구조
```text
📦 lym-bin.github.io
 ┣ 📂 .vscode
 ┣ 📂 css
 ┣ 📂 images
 ┣ 📂 js
 ┣ 📄 index.html        # 메인 홈 화면
 ┣ 📄 search.html       # 동물 검색 페이지
 ┣ 📄 detail.html       # 동물 상세 페이지
 ┣ 📄 shelter.html      # 보호소 페이지
 ┣ 📄 login.html        # 로그인 페이지 (localStorage 기반 데모 인증)
 ┣ 📄 README.md
 ┗ 📄 .gitignore
```

> **API 키 관련**: `js/config.js` 는 의도적으로 커밋되어 있습니다.
> GitHub Pages 는 빌드 단계가 없어 배포 시 키 주입이 불가능하고,
> 사용된 키는 공공데이터포털 유기동물 조회 및 카카오 지도(도메인 제한 적용) 용도라
> 포트폴리오 운영 기간 동안 노출을 감수하는 방식으로 운영합니다.

> **이미지·에셋 안내**: 비공식 리뉴얼 습작입니다.
> 배너/그래픽은 직접 제작, 카드용 동물 사진(입양후기·기부·실종/제보)은 AI 생성,
> 유기동물 목록/상세 사진은 공공데이터 API 제공분입니다.
> 로고·아이콘·지역 썸네일은 원본 서비스(포인핸드)에서 추출해 레이아웃 재현에 사용했으며,
> '포인핸드' 명칭 및 브랜드 자산의 권리는 주식회사 포인핸드에 있습니다. (아이콘 일부 Font Awesome Free)

## 🛠️ 기술 스택 (Tech Stack)
- **Environment**: Git, GitHub
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS, ES6+)
- **Styling**: CSS Custom Properties, Flexbox, Grid
- **API**: 공공데이터포털 유기동물 조회 Open API, 카카오 지도API(geocoding)

## 배포 링크
- **상태**: 추후 배포 예정 (현재 로컬 환경 실행)

## 📌 트러블슈팅 및 주요 고민
- **공공데이터 API 비동기 데이터 바인딩 최적화**: 
  - 대량의 유기동물 데이터를 받아올 때 화면이 멈추거나 깨지는 현상을 방지하기 위해 `async/await`와 예외 처리 블록을 적용하고, 초기 노출 개수를 제한(`displayLimit`)하여 렌더링 성능을 개선했습니다.
- **상태 관리 및 모듈화**:
  - `localStorage`를 활용해 로그인 세션 유지(아이디 저장) 기능을 구현하여 멀티 페이지 간 로그인 상태를 동기화했습니다. (실제 인증 서버 없는 프론트엔드 데모)
